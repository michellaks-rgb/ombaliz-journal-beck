Le journal est conservé uniquement dans ce navigateur sur cet appareil, sans envoi automatique. Il n’est pas chiffré : utilisez un appareil personnel. Effacer les données du navigateur supprime le journal. Téléchargez une sauvegarde régulièrement. Le flashcode contient seulement l’adresse de l’application, jamais vos réponses.
Sur iPhone : Safari → Partager → Sur l’écran d’accueil. Sur Android : menu du navigateur → Ajouter à l’écran d’accueil. L’accès initial nécessite Internet.
Ressource : journal de pensées, NHS. Structure adaptée du document de votre thérapeute. Exemples de cognitions rédigés en français à partir des thèmes EMDR ; ressources : Morgan (2021), EMDRIA et IFEMDR, Les cognitions en thérapie EMDR.
